# recall.works

Personal-scale agent operating system. Two parts:

- **`site/`** — the marketing / explainer site. Static HTML + one CSS file. Deployed to GitHub Pages via `.github/workflows/pages.yml`. Live at <https://stevepaltridge.github.io/recall.works/>.
- **`agent-os/`** — the installable toolkit. Bootstrap script, brain container, helper scripts, templates. Start at [`agent-os/README.md`](agent-os/README.md) and [`agent-os/docs/QUICKSTART.md`](agent-os/docs/QUICKSTART.md).
